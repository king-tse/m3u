### 目录结构
```
my-iptv-repo/
├── .github/
│   └── workflows/
│       └── update.yml          # GitHub Actions 自动化脚本
├── config/                     # 存放配置文件
│   └── config.json             # 你的频道精选与匹配规则
├── scripts/                    # 存放 Python 处理脚本
│   └── filter_epg.py           # 自动化拉取与过滤脚本
├── .gitignore
├── README.md                   # 项目说明文档
└── Gather.m3u                # 主列表（直接放在根目录方便对外提供 URL）
```
