### 目录结构
```
m3u/
├── .github/
│   └── workflows/
│       └── update.yml          # GitHub Actions 自动化脚本
├── config/                     # 存放配置文件
│   └── config.json             # 你的频道精选与匹配规则
├── .gitignore
├── README.md                   # 项目说明文档
├── Gather.m3u                  # 频道源
└── Gather_epg.xml.gz           # 频道源epg节目单
```
